Riskiest assumption

That this is a convention problem upstream can fix

It may be a capability problem no attribute can fix. Kim measured that a self-verification protocol does not reduce false completion, and Hughes argues any check the actor can inspect becomes part of its objective function — which implies actor-emitted telemetry is structurally incapable of being evidence, however well specified.

My counter is narrow: the proposed signal comes from an independent oracle (world state, artifact-contract satisfaction), not self-report. But on this fleet that oracle is the same harness that runs the agent, so independence is asserted, not proven.
