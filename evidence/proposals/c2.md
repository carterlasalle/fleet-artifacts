# C2 — One Rung, No Browser

lens: constraint dispatch — "impose a hard budget, then design inside it"
vehicle: tool

## The move
Budget: no browser, no subprocess, no install, stdlib only, one file, under 120 lines.
Inside that budget I cannot render, so I cannot claim a page draws. What I *can* do is
partition every external reference by the attribute it sits in and refuse to make a
claim above my evidence: `src`/`@import`/`url()` in a style block can cause a fetch;
`href` on an `<a>` is navigation and cannot. The output is a triage list, not a verdict,
and it must say so in its own first line.

## The first version, physically
`ref_triage.py`: walks pages, emits one row per external reference with
`attribute | element | fetch-capable(yes/no) | line`, and a header that states
"I did not open a browser; this is not a render verdict."
