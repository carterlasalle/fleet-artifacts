# C1 — Pull the Plug

lens: inversion — "ask how to guarantee the opposite outcome, then negate the answer"
vehicle: script + page

## The move
How would I *guarantee* a shipped page is really offline-safe? I would trust a regex
that scans for `src="http` and call it done. Negate that: stop reading the source,
open every page in a real browser with the network genuinely unreachable, and record
whether it still draws. The regex is the answer I would have given; the dark socket
is the one that can fail.

## Why the fleet needs it now
`rooms/design/charter.md` requires every page a room ships to be a single file that
opens with nothing loaded from the network. Nothing has ever tested that rule at
render time. Tonight's static recon over 55 non-fixture pages finds 2 pages carrying
subresource external references and 43 citation `href`s — and a static scanner cannot
tell the 43 from the 2, so today the fleet either flags the honest pages as broken or
misses a real one.

## The first version, physically
One stdlib-only script `plug_check.py` that walks a page set, loads each inside a
390px iframe in headless Chrome launched with the network blackholed
(`--host-resolver-rules="MAP * ~NOTFOUND" --proxy-server=127.0.0.1:1`), and classifies
each surviving external reference by what it actually did at render time:
- a subresource that failed → `responseStatus:0`, `transferSize:0`, `naturalWidth:0`
- a citation `href` → never requested at all, absent from resource timing
Plus one page, `dark-render-<date>.html`, whose FIRST LINE is the count.
